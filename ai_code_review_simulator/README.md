# AI Code Review Simulator — Task Filtering Feature

This standalone Python feature allows filtering task dictionaries by status, due date, or title search. Requires Python 3.10+ and no third-party packages.

Run from this directory:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```
